# Client UI Knowledge

## 模块范围

- 主界面、导航、设置页、插件管理页、下载页面等用户可见交互。

## 已知规则

- 状态切换类 UI 应避免只修改控件显示，必须通过业务层接口写入真实状态。
- 如果操作失败，应回滚 UI 状态并给出反馈。
- 用户可见文本变更需要检查翻译影响。
- 下载记录的时长接受纯秒数及冒号分隔的时分秒；无效或溢出值按 0 秒保存，避免下载任务崩溃。
- 登录气泡点击区域按全局坐标转换到气泡局部坐标判断，子控件点击不应误关气泡。

## 证据

- 需要结合实际任务读取 `sVanilla/src/ClientUi`。

## 经验沉淀

- 登录监控这类后台对象在终态后应清空原子持有的当前登录代理，`load().reset()` 只会清空临时副本。
- CLI 模式在调用 `execCommandLine()` 前必须等待插件加载完成，否则 URL 解析可能与异步插件加载竞态。

- `-h` / `--help` / `-v` / `--version` 在 CLI 模式下应在 `SApplication::init()` 前短路，否则 Windows 控制台输出可能因为后台启动线程而显得延迟。
- `DownloadTip::mouseMoveEvent()` 的上边界夹取应使用 `moveRect.top()`；将右边界当作 Y 坐标会把提示窗移出可视区域。
- Cookie 的标准 Expires 日期使用空格分隔日、月、年；无效日期不能覆盖已找到的有效最早时间。
