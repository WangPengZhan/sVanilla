# AI Experience Log

本目录记录可复用的 AI 协作经验，不替代需求、规格或实现知识。

## 记录什么

- 任务中错误的初始判断。
- 文档与代码不一致。
- 构建、测试、权限、编码、平台差异等坑点。
- 对后续 AI 智能体有帮助的提示方式。
- 用户偏好的协作方式。

## 不记录什么

- 无复用价值的流水账。
- 敏感信息。
- 与项目无关的通用废话。

## 文件命名

```text
YYYY-MM-DD-topic.md
```

## 维护规则

- 经验如果已经稳定为工程规则，应迁移到 `harness/standards/`。
- 经验如果是模块实现细节，应迁移到 `harness/knowledge/`。
