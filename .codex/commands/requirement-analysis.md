# 需求分析 Command

请基于用户原始需求、团队规范、sVanilla SDD 和需求档案，输出结构化需求分析，不修改代码。

## 必读

- `AGENTS.md`
- `harness/standards/`
- `harness/specs/svanilla/00-sdd-index.md`
- `harness/specs/svanilla/08-agent-working-rules.md`
- `harness/requirements/README.md`
- 与需求相关的 SDD、需求文件、知识文件和代码入口。

## 输出

使用 `harness/templates/requirement-analysis.md`。如果是新需求，建议同时创建 `harness/requirements/backlog/REQ-YYYYMMDD-short-name.md`。

## 输入

```text
在这里粘贴需求
```
