# Harness + SDD Command

请按 sVanilla 的 Harness Engineering + SDD + Knowledge Loop 流程处理下面的需求。

## 工作要求

1. 读取 `AGENTS.md`。
2. 读取 `harness/standards/` 中的团队规范。
3. 读取 `harness/specs/svanilla/00-sdd-index.md` 和 `harness/specs/svanilla/08-agent-working-rules.md`。
4. 根据需求读取相关 SDD 文件、需求文件和分类知识。
5. 读取实际代码验证文档是否有效。
6. 输出压缩版需求分析、规格设计和评审结论。
7. 如果评审通过，实施代码修改。
8. 运行最小相关验证。
9. 如行为、接口、数据、构建或测试方式变化，同步更新 `harness/specs/svanilla/`。
10. 如需求状态变化，更新 `harness/requirements/`。
11. 如产生可复用实现知识，更新 `harness/knowledge/`。
12. 如产生 AI 协作经验，更新 `harness/ai-experience/`。
13. 最终总结修改、验证、风险、文档更新和需人工确认事项。
