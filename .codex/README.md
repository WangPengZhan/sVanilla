# Codex Adapter

本目录只保存 Codex 专用命令、提示词和适配说明。

共享的 Harness Engineering 资产已经迁移到 `harness/`：

- 团队规范：`harness/standards/`
- SDD：`harness/specs/svanilla/`
- 需求档案：`harness/requirements/`
- 实现知识：`harness/knowledge/`
- AI 经验：`harness/ai-experience/`
- 模板：`harness/templates/`
- 工作流：`harness/workflows/`

新增或更新项目事实时，优先修改 `harness/`。`.codex/commands/` 中的命令也应引用 `harness/`，不要重新维护一份共享内容。
